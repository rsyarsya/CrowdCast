# Draft Visual Direction

**Status: PROPOSED**<br>
**Periode dokumentasi: 11–17 September 2026**

Eksplorasi Week 3 mengarah pada antarmuka monitoring bertema gelap dengan hierarki informasi yang jelas. Dua kategori referensi digunakan untuk membentuk arah awal:

- **Brivo** sebagai referensi dashboard monitoring gelap yang memadukan video CCTV, kartu informasi, dan grafik analitik.
- **CountIQ** sebagai referensi ilustrasi bangunan 3D isometrik untuk elemen pendukung pada login atau pengenalan aplikasi.

Referensi tersebut digunakan sebagai inspirasi arah visual, bukan sebagai aset yang akan disalin ke CrowdCast.

## Prinsip Arah Visual

1. Informasi monitoring menjadi fokus utama, terutama video, people count, crowd status, dan prediksi.
2. Tema gelap digunakan sebagai arah awal untuk mendukung penggunaan dashboard dalam durasi panjang.
3. Ungu, biru, dan warna pastel digunakan secara terbatas sebagai aksen dan pembeda informasi.
4. Elemen 3D bersifat pendukung dan tidak boleh mengurangi keterbacaan data monitoring.
5. Struktur layar tetap mengacu pada low-fidelity wireframe sebelum visual polish ditambahkan.

## Penerapan yang Diusulkan

| Layar | Arah visual |
| --- | --- |
| Login | Layout sederhana dengan ilustrasi 3D sebagai elemen pendukung bila asetnya tersedia dan sesuai. |
| Live Monitoring | Video menjadi elemen dominan, diikuti people count, crowd status, identitas camera, dan prediksi. |
| Monitoring History | Grafik dan tabel menjadi fokus; dekorasi 3D tidak diprioritaskan. |
