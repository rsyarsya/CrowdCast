# CrowdCast

CrowdCast adalah platform pemantauan keramaian berbasis **Computer Vision dan Artificial Intelligence** yang memanfaatkan video CCTV untuk mendeteksi dan menghitung jumlah orang secara *real-time*, mengklasifikasikan kondisi area menjadi **Sepi, Normal, atau Ramai**, serta memprediksi tingkat keramaian dalam waktu dekat. Sistem ini mengintegrasikan teknologi **jaringan komputer, komputasi awan, dan kecerdasan buatan** untuk menyediakan informasi kondisi keramaian yang dapat diakses melalui aplikasi web.
